01

A browser-based preview

This website plays audio from Prapthi's own speech service, so the voices, languages and emotions you hear on these pages are the real ones. A programmatic API with developer keys and audio downloads is not open yet — those live inside the studio account.

02

Prepare a production integration

A production integration needs a speech provider, secure server-side credentials, input validation, request limits and handling for timeouts. Never put a private API key in browser code.

03

Playback and language support

Check whether speechSynthesis is available, load installed voices, and handle end and error events. The playground includes cancellation and text-length limits.

The request format above is illustrative: a developer API with keys is not open yet. The playground on this site needs no account, and is rate limited per visitor.
